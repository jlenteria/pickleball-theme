# Pickleball Theme

Transform your WiFi portal into a nocturnal, floodlit pickleball club experience. The Pickleball Theme brings the energy of the world's fastest-growing sport to your Flarewifi captive portal with a moonlit court backdrop, frosted glass cards, paddle-shaped buttons, and a high-voltage optic-lime accent.

## Features

- **Unified Branding Across All Touchpoints** — Your venue name, logo, and banner stay perfectly aligned across the admin dashboard, guest WiFi portal, and login screens for a consistent brand experience.

- **Night Court Visual Design** — A deep midnight-pine court backdrop with a perspective floor and net, a frosted dark-glass portal card, kitchen-zone panels, paddle-shaped action buttons, and a signature optic-lime accent reserved for the one action that matters on each screen.

- **Complete Venue Identity Control** — Upload your custom club or venue logo, set your brand name, add a welcoming banner image, and configure your court booking URL—all from one centralized settings page.

- **Mobile-First Responsive Layout** — Optimized for every screen size from guests' smartphones to front-desk tablets and staff laptops, with enhanced touch targets (52px minimum) and adaptive spacing that looks great everywhere.

- **Rich Court & Guest Content** — Publish court session rates with pricing and duration, embed tutorial videos or links to teach newcomers how to play, share your court booking website, and recommend gear through affiliate links with preview images.

- **Accessible & User-Friendly** — Built with WCAG 2.1 AA accessibility standards including comprehensive ARIA labels, keyboard navigation support, proper focus states, and readable color contrasts that work in both light and dark environments.

- **Real-Time Session Display** — Live session metrics show remaining time and data with smooth animations, paused/running status indicators, and automatic updates via server-sent events—all styled to match the pickleball aesthetic.

- **Integrated Voucher Redemption** — Guests can enter voucher codes directly from the portal home screen with instant validation, clear error messages, and automatic connection upon successful redemption.

- **Performance Optimized** — Smooth animations respect `prefers-reduced-motion`, efficient CSS with minimal repaints, pre-allocated data structures in Go code, and graceful degradation when API calls fail.

- **Developer-Friendly Codebase** — Clean separation of concerns with modular helper functions, comprehensive input validation, proper error handling with contextual logging, and extensive inline documentation for easy customization.
